# 个人资料

只在本文件维护个人事实。空白表示未知；确实没有填“无”，不适用填“不适用”。字段值填冒号后；不要改字段名。日期用 YYYY-MM-DD 或 YYYY-MM，年月不能补成虚构日。重复经历复制小节并分配新编号；多行内容缩进到字段下。自填编号须唯一；空模板的小节标题不是有效编号。

敏感或条件字段仅在官网要求时填。声明会变化，须有适用范围和确认日期。附件只在末尾登记相对工作区路径，经历通过附件编号关联；多个编号用中文逗号分隔。无记录的小节保留空白或在第一字段填“无”。
