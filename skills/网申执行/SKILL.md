# 网申执行

读取工作区约定、`个人资料.md`、目标公司总览和 APP。浏览器操作使用 Edge Control：

```text
edge_bridge_status → edge_list_tabs → edge_navigate / edge_get_dom
→ edge_wait_for / edge_click / edge_type → edge_get_dom 回读
```

## 填写

1. 检查账号已有申请、岗位状态和投递限制，确认本次志愿。
2. 读取真实表单，记录必填字段、字符限制、附件语言与格式大小。
3. 为每个页面字段写入源章节或记录编号；拟填内容只使用资料中的事实。
4. 上传官网要求的简历，等待解析结束，再逐字段覆盖和清洗。
5. 按附件编号取得本地路径，用 CDP 注入文件输入，并回读文件名。
6. 技能选项按页面选项与资料中的已确认程度完整匹配。
7. 长文本失焦后用 `edge_get_dom` 回读；错误值继续修正。
8. 全表读取一次，核对字段来源、必填项、上传结果和重要声明。

字段准备完成后将 APP 置为“待提交”，列出岗位、志愿、附件、声明和未解决项，取得本次提交授权。

## 提交

获得授权后执行页面提交动作。出现错误或超时，先检查账号申请记录和页面回执，再决定下一步。

官网成功回执记录：

- 提交时间
- 申请编号或回执位置
- 实际附件
- 已确认志愿
- 关键答复

## 收尾

同步 APP、公司总览和 `90_投递总览.md`。测评记录为未通知、已邀请、已完成或已出结果。提交后把 APP 收敛为结果记录，清理字段映射和临时快照。
