# 岗位调研

读取工作区约定、`个人资料.md`、`求职意向.md` 和已有公司总览。普通检索用于发现线索；招聘页面读取、交互和抓取使用 Edge Control：

1. `edge_bridge_status`
2. `edge_list_tabs`
3. `edge_navigate` 或 `edge_crawl_*`
4. `edge_get_dom`、`edge_query` 提取页面事实

## 调研

1. 用户已给公司时直接调研；未给时按行业、职位和城市提出少量候选。
2. 找到公司官网或官方招聘域名，记录岗位列表、岗位直链或职位编号。
3. 核验批次、城市、部门、届别、专业、语言、实习时长、出勤、工作许可和截止日期。
4. 核验投递次数、志愿顺序、跨城市或跨项目并投、撤回与修改规则。
5. 人数、薪资和规则记录官方来源与查询日期；未公开写“未公开”。
6. 用 [公司总览](../../模板/公司总览.md) 保留候选、最终建议、必要依据和待核实项。

用户确认岗位和志愿后，用 [申请记录](../../模板/申请记录.md) 创建一份 APP，并带入职位、官网链接、志愿顺序和投递限制。交接 `$job-apply`。
