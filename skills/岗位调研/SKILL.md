# 岗位调研

先读工作区约定、最新个人资料和求职意向。来源与记录规则见新工作区使用的 [工作约定](../../模板/工作约定.md)。

普通网络搜索可用于发现链接；进入网页读取、抓取或操作前必读 [Edge配置](../环境配置/references/Edge配置.md) 和已安装的 `edge-browser-ops`，通过 Edge Control 的状态检查及标签页列表选择用户实际会话。桥接缺失暂停浏览器阶段，不回退内置浏览器、Computer Use 或其他浏览器工具。

1. 用户给公司则直接研究；没给时根据方向提出少量公司候选。搜索官方域名和招聘入口，从公司官网跳转关系验证第三方招聘平台，不向广告、培训或聚合站上传资料。
2. 先登记官方列表及岗位直链/职位编号，再核验批次、城市、业务线、学历届别、专业、语言、实习时长、出勤、工作许可、截止日期。将硬性满足、缺失、待核实分开。
3. 查项目级、岗位级和账号级规则：提交次数、志愿顺序、跨城市/跨项目并投、撤回修改。公开规则不能证明账号剩余次数；不登录也能完成公开研究。
4. 人数、薪资、地点和规则引用官方原文要点、来源、查询日期；未公开写未公开。截止字段异常或来源相互矛盾时明确说明，不把匹配度变成录取概率，不用浏览量估算竞争。
5. 用 [公司总览](../../模板/公司总览.md) 保留少量候选和最终建议、必要依据及未知项。个人匹配引用源章节，不复制整份简历；不保存岗位全集、接口转储和长调研报告。
6. 用户确认岗位、志愿后创建一份 [申请记录](../../模板/申请记录.md)，将本次投递限制和官网链接带入。用户未确认前不选择不可逆志愿或提交。一个表多个志愿只有一个 APP，跨表分别编号。

交接网申执行：目标岗位、志愿顺序、来源链接、关键限制与待核实资格。
