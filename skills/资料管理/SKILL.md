# 资料管理

读取用户工作区 `AGENTS.md`，按其中约定维护资料。

## 初始化

1. 将 [个人资料](../../模板/个人资料.md) 复制为 `00_基础资料/个人资料.md`。
2. 将 [求职意向](../../模板/求职意向.md) 复制为 `00_基础资料/求职意向.md`。
3. 创建 `01_附件库/` 与 `02_公司/`。
4. 创建简洁的 `90_投递总览.md`，列为公司、申请、状态、测评、来源/日期、下一步。
5. 已有事实源继续沿用，按需迁移字段，不另建平行版本。

## 填写

- 引导用户直接编辑 Markdown，值填在字段冒号后。
- 空白表示未知；确定没有时填“无”，条件性信息按官网要求填写。
- 重复经历复制同一小节并分配唯一编号。
- 附件只在资料末尾登记元数据和相对路径；经历通过附件编号引用。
- 聊天中新增的个人事实先确认，再写入对应字段。

## 检查

运行：

```powershell
node "<插件目录>/脚本/检查资料.mjs" "<用户工作区>"
```

把检查结果整理为需要用户处理的文件、章节、字段和原因。修改后复查重复编号、附件引用和日期。只输出待处理项，不创建独立检查报告。

完成后读取求职意向，交接 `$job-research`。
