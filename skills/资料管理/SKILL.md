# 资料管理

读取用户工作区 `AGENTS.md`，按其中约定维护资料。

缺少工作区文件时运行：

```powershell
powershell -ExecutionPolicy Bypass -File "<插件目录>\脚本\初始化工作区.ps1" -Workspace "<用户工作区>"
```

已有文件保留并按需迁移字段，不建立平行版本。个人事实在 `个人资料.md` 中直接维护；经历号、附件路径和声明日期按模板填写。聊天新增事实先取得确认，再写入源文件。

## 检查

修改后运行：

```powershell
node "<插件目录>/脚本/检查资料.mjs" "<用户工作区>"
```

只输出需要用户处理的文件、章节、字段和原因，不创建检查报告。完成后读取求职意向并交接 `$job-research`。
